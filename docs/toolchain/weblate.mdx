# Weblate

Uyuni documentation translations are managed in Weblate.

Multi-Linux Manager 5.1 and 5.2 are **not** connected to Weblate. [Vistatek](https://www.vistatek.com/) maintains a fork of each release branch, runs AI translation, and opens a pull request against that branch to update the translation files.
